# WanderLog (workspace)

This workspace contains the WanderLog React application scaffold inside the `vite-project` folder.

Quick start (from this repository root):

1. Open a terminal and change into the app folder:

```powershell
cd "c:\React Pratice\Wonderlog\vite-project"
```

2. Install dependencies and run the dev server:

```powershell
npm install
npm run dev
```

3. Build for production:

```powershell
npm run build
```

Notes:
- The app uses the REST Countries API and Reqres for demo auth. If you have a Reqres project API key, set `VITE_REQRES_API_KEY` in an `.env` file in `vite-project`.
- The running dev server is served at `http://localhost:5173/` by Vite.

See `vite-project/README.md` for more internal details.
